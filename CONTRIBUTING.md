# Contribuir a MachoMedic

Gracias por querer alargar la agonía (productiva) del proyecto.

## Antes de codear

1. Lee [`README.md`](README.md) y [`docs/CONCEPTO.md`](docs/CONCEPTO.md).
2. Respeta [`docs/AVISO-MEDICO.md`](docs/AVISO-MEDICO.md): **nada** que parezca consejo médico real.
3. Mantén el tono: humor negro, burlón, pícaro — nunca cruel con sufrimiento auténtico.

## Setup

```bash
npm install
npm run dev
```

## Qué aportaciones encajan bien

- Claridad en el **tracking de medicamentos** (sin volver la UI un hospital serio).
- Copy coherente con la voz de marca.
- Accesibilidad básica y mobile (las señoras también usan el teléfono en la cocina).
- Bugs de timers, `localStorage`, audio o permisos del navegador.

## Qué no encaja

- Features que diagnostiquen o dosifiquen “en serio”.
- Reescrituras masivas sin conversación previa.
- Dependencias pesadas para algo que puede resolverse en vanilla JS.

## Pull requests

- Branch descriptiva, commits claros.
- Si cambias copy visible, revisa que siga siendo gracioso **y** útil.
- Actualiza `CHANGELOG.md` cuando agregues una feature de verdad.

## Código de conducta (versión sofá)

Sé decente con otras personas. Burlarse del *arquetipo* del enfermo dramático está permitido; atacar a alguien por su salud, género u origen no lo está.

Si el PR hace reír y además ayuda a no olvidar el paracetamol: merge mental asegurado.
